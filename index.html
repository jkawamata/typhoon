このソフトの使い方

選んだアメダス観測点の実測・予測と、台風の進路、気象庁の発表をまとめて確認できます。

  1. 地点を選ぶ「地図で観測点を選ぶ」から点の周りや名前をタップ。市町村も自動で決まります。
  2. 時刻を動かすグラフを左右にドラッグすると、全6項目の縦線と数値が連動。指を離すとその時刻を保持します。
  3. 期間を変える「1日前・3日前・7日前」と予測期間で調整。「最新の観測時刻」で現在の観測に戻れます。
  4. 台風を確認する地図はピンチで拡大・縮小。進路の点や日時をタップすると、その時刻をグラフにも表示します。

表示中は5分ごとに取得を確認。「今すぐ更新」でも確認できます。実線・濃い棒は観測、破線・淡い棒はモデル予測です。警報や避難情報は気象庁・自治体の最新発表も確認してください。

観測・予測の違い、更新と欠測について

観測と予測

実線・濃い棒は気象庁アメダスの観測値、破線・淡い棒は選択したアメダス観測点の座標付近の予測です。予測は Open-Meteo JMA API を通して取得した気象庁の数値予報モデル（MSM/GSM）です。気象庁が発表する地域の天気予報や警報とは別の値です。モデルの更新は数時間ごとで、5分ごとに予測が変わるわけではありません。

雨量は表示時刻までの1時間の量（mm）です。風はアメダスの平均風速とモデルの地上10m風速を比較します。最大瞬間風速は観測値だけを別記し、予測風速から推定しません。気圧は比較のため海面気圧を使用します。現地気圧と混ぜません。

未観測・欠測・正常値以外の品質フラグは「—」にします。線は欠測をまたいで結びません。数値予測のピークは表示期間内の計算値で、防災上の警戒基準ではありません。

地区は気象庁の地域気象観測所一覧（2026年3月24日適用）と警報区域を照合した対応表を内蔵しています。2026年9月20日に全1,286観測点を確認し、市町村名と警報用の区域を別々に保存しています。登録済みの観測点は通信なしで地区を確認できます。移設・区域変更時は対応表を更新します。未登録の地点は境界データで照合し、確認できない場合は地区を未確認とします。

日照時間は各時刻までの1時間分を時間単位で表示します。気象庁の日照値には衛星等による推計値も含まれます（気象庁の説明）。モデルの日照予測は配信のある期間のみ表示し、期間外は「予測データなし」にします。

天気アイコンはOpen-Meteoの天気コードを日本語で表示したモデル予報です。過去の天気もモデルの値です。

更新と通信

表示中は5分ごとに発表・観測を確認し、時間別予測は30分ごとに再取得します。「今すぐ更新」はすべて再取得します。タブへ戻ったときや通信が復帰したときも確認します。端末のスリープ・ブラウザー終了中は更新できません。

通信先は気象庁（観測・台風・発表）、Open-Meteo（観測点の座標）、国土地理院（進路地図の淡色地図・観測点選択の白地図タイル）です。選んだ観測点・自動判定した地区、取得済みデータをこのブラウザーに保存します。現在地の表示ではブラウザーの位置情報機能を使用し、表示範囲に応じた地図画像を国土地理院から取得します。アカウント登録、広告、アクセス解析はありません。

取得に失敗した場合は前回値と取得時刻を残し、「更新失敗」を表示します。観測は40分、台風発表は6時間、概況は18時間を超えると遅延に注意する表示になります。警報は発表間隔が一定でないため、発表時刻と取得時刻を分けて表示します。警報の取得失敗を「警報なし」と扱いません。

確認日：2026年9月20日。利用条件の要点をまとめています。正確な条件と最新情報は、各提供元のリンク先で確認してください。

このアプリはHTMLファイル1個で動作します。保存したHTMLをブラウザーで開くだけで使えます。サーバーの起動や、ほかのファイルのコピーは不要です。端末に保存すれば、ご自身で自由に改変できます。ぜひバイブコーディング等で改変してみてください。気象データと地図の表示にはインターネット接続が必要です。表示中の観測値や個別設定は、このHTMLには含めません。
